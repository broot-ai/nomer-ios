# Госномер для iPhone

Родное iOS-приложение игры @GosnomerGame: SwiftUI и «жидкое стекло» iOS 26. Работает с тем же сервером, что и Mini App, поэтому баланс, номера и прогресс общие.

## Что есть сейчас (этап 1)
- Вход через бота @GosnomerGame (подтверждение кнопкой в Telegram, пароль не нужен).
- Проверка участия в группе игры.
- Крутка всех 13 видов номеров: уровни, ×1/×5/×10, шансы редкости, барабан с трещоткой и вибрацией, продажа выпавшего.
- Коллекция: поиск, фильтр по редкости, сортировка, карточка номера с разбором оценки, продажа.
- Профиль: уровень, баланс, звёзды, валюты, награда дня, статистика, выход.
- Раздел «Госномер» в Настройках iPhone: вибрация, звук, быстрая крутка, адрес сервера.

Гараж, рынок, аукционы, гонки, банк и чаты — следующие этапы; пока они открываются в игре в Telegram.

## Сборка
Каждое изменение в `main` автоматически собирается на облачном Mac GitHub (≈10–15 мин).
Готовый файл: вкладка **Actions** → последний зелёный запуск → внизу **Artifacts** → `Gosnomer-ipa`.
Если сборка упала, список ошибок лежит в ветке `build-log` (файл `errors.txt`).

## Установка на iPhone (Sideloadly)
1. Скачайте и распакуйте `Gosnomer-ipa` — внутри `Gosnomer.ipa`.
2. Откройте Sideloadly (https://sideloadly.io), подключите iPhone кабелем, перетащите `Gosnomer.ipa`, введите Apple ID, нажмите **Start**.
3. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**.
4. Если попросит — включите Настройки → Конфиденциальность и безопасность → **Режим разработчика**.

С бесплатным Apple ID приложение работает 7 дней, потом переустановите тем же способом (данные игры на сервере, ничего не теряется).

## Сервер
Нужен `worker.js` с входом для приложения (`/ia/start`, `/ia/poll`, `/ia/logout`). Адрес по умолчанию — `https://nomer.brootai.workers.dev`, меняется в Настройках iPhone → Госномер → Сервер.
