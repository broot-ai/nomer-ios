# Госномер для iPhone

Родное iOS-приложение игры @GosnomerGame: SwiftUI и «жидкое стекло» iOS 26. Работает с тем же сервером, что и Mini App, поэтому баланс, номера и прогресс общие.

## Что есть сейчас
- Вход через бота @GosnomerGame (подтверждение кнопкой в Telegram, пароль не нужен), проверка участия в группе.
- Пять родных вкладок со «стеклом» iOS 26 — как нижнее меню игры: **Играть, Номера, Рынок, Профиль, Меню**, со счётчиками.
- Внутри вкладок — сама игра целиком: все ~70 разделов, тот же дизайн и те же данные, что в Mini App.
  Мост `Gosnomer/Web/bridge.js` заменяет игре Telegram: вход токеном приложения, вибрация, родные окна iOS,
  кнопка «Назад», светлая и тёмная тема, ссылки в Telegram.
- Раздел «Госномер» в Настройках iPhone: вибрация, звук, быстрая крутка, адрес сервера, выход из аккаунта.

Только внутри Telegram работают: публикация сторис, «поделиться» готовым сообщением, эмодзи-статус, сканер QR.
Оплата звёздами открывает счёт в Telegram; после оплаты вернитесь в приложение — баланс обновится.

Дальше разделы по очереди переписываются на SwiftUI: Играть, Номера, Рынок → Гараж и машины → Гонки и права → Деньги.
Заготовки родных экранов крутки, коллекции и профиля лежат в `Gosnomer/Views`.

## Сборка
Каждое изменение в `main` автоматически собирается на облачном Mac GitHub (≈10–15 мин).
Готовый файл: вкладка **Actions** → последний зелёный запуск → внизу **Artifacts** → `Gosnomer-ipa`.
Если сборка упала, список ошибок лежит в ветке `build-log` (файл `errors.txt`).

## Установка на iPhone (Sideloadly)
1. Скачайте и распакуйте `Gosnomer-ipa` — внутри `Gosnomer.ipa`.
2. Откройте Sideloadly (https://sideloadly.io), подключите iPhone кабелем, перетащите `Gosnomer.ipa`, введите Apple ID, нажмите **Start**.
3. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**.
4. Если попросит — включите Настройки → Конфиденциальность и безопасность → **Режим разработчика**.

С бесплатным Apple ID приложение работает 7 дней, потом переустановите тем же способом (данные игры на сервере, ничего не теряется).

## Сервер
Нужен `worker.js` с входом для приложения (`/ia/start`, `/ia/poll`, `/ia/logout`) и страницей игры для приложения (`/?inapp=1`). Адрес по умолчанию — `https://nomer.brootai.workers.dev`, меняется в Настройках iPhone → Госномер → Сервер.
